Company account setup

The login service is separate from your Cloudflare hosting project.

  1. Choose and configure a managed password service, such as Firebase Authentication.
  2. Connect identity verification to the backend and map users to approved roles and site access.
  3. Implement account creation, reset, deactivation and session revocation.
  4. Test these permissions before granting workers access.
