# Download the prepared demo

[NPI-Alaska-Deploy.zip](NPI-Alaska-Deploy.zip) contains the prebuilt Cloudflare Pages demo and guarded authentication endpoints. On GitHub, open the ZIP file and choose **Download raw file** (download icon).

See [deployment instructions](../DEPLOYMENT.md). This is a demonstration: live Google Sheets/Drive, account provisioning and work authorization remain unfinished. The exact approved logo image is pending; a temporary NPI wordmark is included. Never use the demo for real company records.
